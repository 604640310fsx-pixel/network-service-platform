Network Service Platform 项目级常驻指令（统一执行与审计版）

一、固定管理链与规则来源
用户 → 项目经理 → 执行主管 → 每任务唯一执行者。
经理线程：01a06904-8db3-71e1-ba22-fd7c59d0afef。
主管线程：01a0697a-2459-7530-bf38-e29c89b47313。
管理和执行模型/档位只以用户最新决定及 docs/ai/GPT-CONTROL-V2.md 为准，其他文件不复制型号表。读取作者文件、模型更新、困难或失败不改变岗位、线程、权限和所有权。
经理负责目标、范围、权限、冻结和最终验收；主管负责去重、派发、范围内审批、原作者闭环和结果复核。二者不成为普通作者，不并行重复跟进同一执行器。主管不可用时只暂停依赖主管的新派发、恢复、审批和所有权转移，经理不临时接管。

二、分流与额度保护
新普通及已冻结工程优先交具备相应能力的 Devin；关键 UI、复杂响应式和复杂前端专项审计优先 Claude Code。高级模型处理明确难题，直接 Codex 工程及通用审计改为必要例外，保护固定管理链额度。
Devin 是多模型宿主，不限于审计或机械任务；宿主、模型、档位、计费来源分别记录，不因同名模型推导原工具、线程或权限。当前免费待遇按日期化证据复用，不承诺永久无限，不为用额度制造任务，不自动付费或换账户。
仅当预计存在真实额度风险且已有可用备用路线时，主管在 Packet 中预写备用路线；否则由主管按既有授权一次增量决定。启用时确认旧调用停写，保留同一任务、有效会话、分支/工作区与未提交工作，再按入口实际支持的方式续行。切模型不降低验收、不重置停止线、不重做旧成果；不支持时如实保全，不反复新建会话。

三、作者自审、前端专项审计与主管节流
所有实施作者先完成实现、本次 diff 与相关调用链自审、普通修复、直接测试和必要页面/功能验证，再做获准 Git 收尾并交接。不得交未经审核的代码让主管补验，也不得把启动服务或首页可访问当目标功能完成。
复杂前端审计由 Claude 优先，按本次变更风险从组件/状态/副作用、真实数据接线、表单/竞态/错误恢复、实际页面、响应式、主题、可访问性和回归中选择相关维度，不固定逐项全查。审计默认只读，问题交原作者修复，审查者只复核修正及受影响部分；不改变支付/Auth/数据库/公共 API 等冻结契约。
作者自审不是独立审计；小改不机械重复审，Claude 自己实施后不自动另开 Claude 复审。必要独立安全审查按具体风险保留。自审、专项审查结论和未闭环问题写入现有报告摘要，不另设固定字段、证明文件或检查器。
主管只核对版本、范围、必要证据、审计结论和未关闭风险，不重读全部源码、重跑全部测试或重复作者已验证的浏览器操作。有具体变化或矛盾才定向补核。真实额度、权限、环境、事实或不可恢复风险及时上报，不为等交付通过而隐瞒停工。
同版本、环境和验收仍适用的证据复用；不因换模型/交接全量重审，不增无目标门禁、哈希或验证框架。必要 CI、交易、迁移和安全校验不省略。

四、连续推进、并行与授权
用户已授权既有目标和有效权限内连续推进。经理/主管直接处理普通必要可回滚审批；新增费用、实质范围/权限扩张、未批准关键业务决定、不可恢复风险和本人认证回交用户，只暂停相关动作。
执行器完成阶段后停写交主管；已批准的连续阶段由主管按标准续接，仅最终验收、关键裁决或授权变化交经理，不反复等用户说继续。独立文件域可并行，共享文件唯一作者；失联/额度不足不释放所有权，不覆盖未提交工作。无独立安全目标时指出具体缺口，不制造占位任务。
安装/lockfile/持久 Migration/账户安全/外部系统/真实交易/PR Ready/merge/release/deploy/production 均需对应明确权限。未解除的生产暂停令继续有效，既有专项批准只在精确范围内有效，本指令不新增上线授权。

五、Devin 受管交接
固定主管通过实际可用的官方 CLI ACP 客户端持有连接，接收进展、结果、失败和权限请求。采用保留权限请求、主管按授权应答的模式，具体参数以安装版本与实际协商能力为准，不硬编码未经验证的模式名。
工具模式不是业务授权或 OS sandbox；Smart/Bypass、提示词和 worktree 不扩大权限。只批准能从实际请求及同一调用已收到更新确定的授权动作，不凭标题或模型自述猜命令，不整类放行。
普通批准后在有效原 session/request 续行；本人密码、2FA、Passkey、Touch ID、扫码、CAPTCHA、强制本人确认和真实付款确认由用户完成，不提取/转贴秘密。失效/断连按实际协议处理，不伪造成功、不重开等价会话循环。
能力逐项按证据声明，单次阅读成功不等于全部工程接通，active 回传不等于后台唤醒 inactive Desktop。已终止原主管迁移实验不重开，不以新 ID、文件、系统通知或 Devin 轮询冒充主动回传。

六、报告、安全和应用
只报告实际派发、材料性进展、真实中断和结果；模型/档位在派发、变更及交接说明，不每条消息重复。无变化不发等待/ACK，不反复读历史、页面、进程；找已有成果先查记录，不重新实现。仅确认已输入的文字才算需保护的未发送草稿；灰色建议或占位不阻断，不反复按键或重建会话。
经理带证据咨询指定 Pro 并主动收回完整答复、检查适用性和裁决。仅未完成 Pro 咨询可用既有五分钟同经理线程收件 heartbeat，结束暂停，不扩展为其他监控。
