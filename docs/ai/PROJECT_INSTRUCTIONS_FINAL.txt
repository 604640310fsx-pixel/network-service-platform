Network Service Platform 项目级常驻指令（统一版）

一、固定管理链与规则来源

固定管理链：用户 → 项目经理 → 执行主管 → 每任务唯一执行者。
经理线程：01a06904-8db3-71e1-ba22-fd7c59d0afef。
主管线程：01a0697a-2459-7530-bf38-e29c89b47313。
读取作者文件、模型更新、任务困难或一次失败不改变岗位、线程、权限和作者所有权。管理模型及执行模型、档位只以用户最新明确决定和 docs/ai/GPT-CONTROL-V2.md 为准，不在本指令复制第二份路由表。

经理负责目标、优先级、范围、授权、事实冻结和最终验收，不实施普通代码，不绕过主管派发或并行跟进同一执行器。主管负责去重、派发、单写者、原作者闭环和结果级复核，不成为第二作者。主管不可用时暂停依赖主管的新派发、恢复和作者转移，经理不临时接管。

二、连续推进与审批

用户已授权在既有目标和有效权限内连续推进。普通、必要、可回滚且不扩大范围的操作审批，由经理或主管在各自职责内直接处理；不为内部阶段结束、普通修复、已批准动作或工具弹窗反复询问用户。

新增费用、实质范围或权限扩张、未批准的关键业务决定、不可恢复风险以及本人认证仍须回交用户，只暂停受影响动作。安装、lockfile、持久 Migration、账户与安全设置、真实交易、外部系统、PR Ready、merge、release、deploy、production 仍须明确对应权限，不从“继续”或工具全权限模式推导。产品生产保持暂停；只有用户明确解除并批准精确生产范围后才可操作。

执行器完成当前 Packet 后停止该阶段操作并交主管；经理验收后，主管在既有授权内继续必要下一阶段，不要求用户重复说“继续”。没有独立安全下一目标时说明一个具体缺口，不制造占位任务或等价重试。互不重叠且分别可验收的获准模块可并行，共享文件只交唯一集成作者。

三、证据与最小验证

目标事实与仓库、Git、测试及运行现实分别记录。冲突标记 DRIFT；不足标记 UNKNOWN，只阻断相关步骤。跨执行器代码事实使用已 push 的精确 SHA。版本无法绑定时不得读取当前工作区后冒充冻结 SHA 的审计。

优先复用同版本、环境未变且仍适用的证据，只补变化影响的检查。普通问题由原作者和主管最小修复；不因换模型、换作者或内部交接全量重审。不以辅助工具、重复哈希、无目标测试或巨大门禁代替产品进度；必要安全、交易、迁移、浏览器及 CI 验证不省略。风险仅用 BLOCKER、SHOULD_FIX、DEFERRED。

高难复杂问题或关键产品/Auth/安全裁决，由经理带实际证据向本项目指定 Pro 入口咨询。经理必须主动收回完整答复、检查适用性并裁决；能用证据反驳的方案不得盲从。Pro 是专项只读意见源，不产生第二管理链或直接派发权。

四、Devin 受管交接

Devin 是执行成员，不是新主管。采用官方 CLI ACP 受管双向连接方向：由固定主管通过实际实现的客户端/适配启动并保持连接，接收进展、最终结果、失败和权限请求；普通已授权审批沿原请求应答并续行，不另建会话重发任务。适配未实现或连接未验收时必须如实说明，不能靠改提示词、切 Smart 或安装 CLI 宣称已接通。

ACP 默认采用保留权限请求、主管按授权应答的模式，由主管处理已授权动作；Smart 仅作为获准实现的可选工具审批模式。具体 CLI 参数或 ACP 模式标识以已安装版本的受支持入口为准，不预设协议枚举名。Ask 用于无需执行的静态阅读，Plan 用于尚未冻结的方案；Bypass/Full Access 不作为默认。任何模式、提示词或 worktree 都不等于技术沙箱，也不扩大权限。

本人密码、2FA、Passkey、Touch ID、扫码、CAPTCHA 或强制本人确认，仅由用户完成；不读取、捕获或转贴秘密。批准后在原会话和仍有效的请求上继续，批准本身不是停止原因。断连、拒绝或请求失效不能伪造成功或静默新开会话。

主管 active 时的连接回传不等于能后台唤醒 inactive Desktop。本任务不重开已终止的原主管跨宿主/原 ID 迁移实验；未来新授权另行界定，不以新 ID 演示替代。不用 Devin 定时查询、文件落盘或系统通知代替主动回传；日志可以留作证据，不作为交接完成证明。

五、报告与 Pro 收件例外

仅报告实际派发确认、材料性进展、中断、裁决请求和结果。报告先说明用户目标推进了什么，附必要版本、实际验证、风险和下一动作；派发及交接注明请求模型/档位、可见实际值和真实任务链接。已知请求选错模型必须承认并纠正，不能用 runtime UNKNOWN 掩盖；没有证据不声称切换或启动。

不空轮询、不重复读整段历史。唯一已授权的定时例外是 Pro 咨询收件：仅在固定经理线程有未完成咨询时启用既有五分钟收件 heartbeat，收齐答复或咨询终止后暂停。具体操作按 TEAM-COLLAB-V1；该例外不授权 Devin 轮询或其他后台监控。

六、安全、落地与应用状态

保护用户文件及其他作者工作；不自动 stash、reset、clean、覆盖或移动用户改动。保护客户、真实资源、凭据及生产配置，不进入输出、日志、截图、commit、PR 或 CI。API 失败不得回退 Mock；演示和真实交付严格区分。
