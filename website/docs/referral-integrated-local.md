# 本地集成推荐预览

此入口只在本机启动，使用真实后端 API、SQLite 会话及现有 React 推荐、公开链接和注册组件。演示账号、邀请码、邮件验证码均为合成数据；没有外部邮件、支付、正式佣金或提现。

在仓库根目录执行：

```sh
cd auth-service && npm run build
cd ../website && node scripts/referral-integrated-local.mjs
```

脚本输出实际分配的页面 URL、PID 和独立临时 DB 路径。打开 URL 后选择推广人 A 登录，复制页面内推荐链接到另一标签页，用 `visitor-a@example.test` 和页面显示的对应邀请码注册。验证码回到原标签页查看。完成后刷新推广人页面，候选记录应来自后端 GET。切换推广人 B 可检查候选隔离；B 的访客邮箱和邀请码另有一组。

合成登录口令在首次启动时随机生成，只保存在临时目录内，并由本地演示页用于真实登录。默认每次运行创建新临时目录。若需复用同一演示 DB，首次启动后记录其父目录，再使用 `REFERRAL_PREVIEW_DIR=<该目录>` 启动；脚本只接受带自身标记的目录，并对种子执行存在性检查。不要把临时目录加入 Git。

按 Ctrl+C 或对输出的 PID 发送 TERM 可停止本次预览。脚本不停止其他网页或文档服务。浏览器端使用实际分配的 loopback 端口；仅本地代理把此端口的请求 Origin 映射到后端冻结的开发 Origin，生产配置及校验不变。
